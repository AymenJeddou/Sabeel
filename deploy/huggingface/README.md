# Sabeel · سبيل

Pothole reporting and management for Tunisia: report from any phone browser,
AI severity grading, law-based routing to the right office, cited work orders,
public transparency page.

- Public page: `/`
- Report a pothole: `/#/report`
- Authorities: `/#/overview`
- API docs: `/docs`

Source code: https://github.com/AymenJeddou/Sabeel. This Space is deployed by
`.github/workflows/deploy-hf.yml`; the database and photos live in Supabase.
